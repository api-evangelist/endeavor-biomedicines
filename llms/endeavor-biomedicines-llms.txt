# Endeavor BioMedicines

> Clinical-stage biotechnology company in San Diego, California developing medicines
> intended to reverse the course of life-threatening fibrotic and oncologic disease.
> Lead candidate taladegib (ENV-101), a Hedgehog pathway inhibitor in clinical
> development for idiopathic pulmonary fibrosis; also in-licensed HMBD-501, a
> next-generation HER3-targeted antibody-drug conjugate. Endeavor BioMedicines runs
> no developer program and sells no API. The machine-readable surface described below
> is the public WordPress REST API of its corporate website, plus an
> authentication-gated WordPress MCP server on the same host.

## APIs

- [WordPress REST API](https://endeavorbiomedicines.com/wp-json/): Public route index.
  316 routes across 16 namespaces. Content reads answer anonymously.
- [Posts](https://endeavorbiomedicines.com/wp-json/wp/v2/posts): Corporate press
  releases as JSON. Paged with `page` / `per_page`; totals in `X-WP-Total` and
  `X-WP-TotalPages`; `Link: rel="next"` for the next page.
- [Pages](https://endeavorbiomedicines.com/wp-json/wp/v2/pages): Science, pipeline,
  therapeutic-area, about and legal pages as JSON.
- [Members](https://endeavorbiomedicines.com/wp-json/wp/v2/member): Leadership, board
  and advisor roster.
- [Media](https://endeavorbiomedicines.com/wp-json/wp/v2/media): Media library.
- [Categories](https://endeavorbiomedicines.com/wp-json/wp/v2/categories) and
  [Tags](https://endeavorbiomedicines.com/wp-json/wp/v2/tags): Taxonomies, including
  year-based news categories.
- [MCP server](https://endeavorbiomedicines.com/wp-json/mcp/mcp-oauth-server):
  Live but gated. Anonymous `initialize` and `tools/list` return HTTP 401
  `mcp_unauthorized`. Requires an OAuth 2.1 bearer token in the `mcp` scope.

## Notes for agents

- No rate limits are published and none are signalled at runtime. Self-govern.
- No idempotency contract. Do not retry writes blindly.
- Errors use the WordPress envelope `{"code","message","data":{"status"}}`, not
  RFC 9457 problem+json.
- No status page, no deprecation policy, no changelog, no SDKs, no CLI, no sandbox.
- No A2A agent card: `/.well-known/agent-card.json` and `/.well-known/agent.json`
  both return HTTP 404.
